# RTA Ambiental — Modernização do Site Institucional


![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![Projeto](https://img.shields.io/badge/projeto-RTA%20Ambiental-green)

## 📌 Sobre o projeto

Este repositório contém o desenvolvimento da nova plataforma institucional da **RTA Ambiental**, com foco na modernização completa do site, melhoria da experiência do usuário, responsividade, segurança, SEO, gestão de conteúdo e modernização dos canais de atendimento.

O projeto será desenvolvido, contemplando as funcionalidades previstas no escopo mais completo da proposta de modernização.

## O novo site deverá substituir a estrutura atual por uma experiência mais moderna, limpa, responsiva e preparada para futuras estratégias digitais. A necessidade de redesenho e melhoria da experiência em dispositivos móveis foi definida como uma das prioridades do projeto.

## 🎯 Objetivos

* Modernizar completamente o site institucional da RTA Ambiental.
* Criar uma experiência responsiva para celular, tablet e desktop.
* Apresentar os serviços atuais da empresa de forma clara e organizada.
* Atualizar os conteúdos institucionais.
* Melhorar a estrutura técnica e a performance do site.
* Implementar boas práticas de SEO.
* Criar mecanismos seguros para comunicação através do site.
* Implementar um **Banco de Talentos**.
* Criar um **painel administrativo** para gerenciamento de conteúdo.
* Implementar **múltiplos usuários com permissões por função**.
* Modernizar o atendimento através de integração com **WhatsApp/Chatbot**.
* Preparar a plataforma para futuras expansões.

---

# 🚀 Escopo 

 contempla todas as funcionalidades previstas nos pacotes anteriores, acrescentando recursos de gestão, controle de usuários e atendimento.

## 🎨 1. Novo design e experiência do usuário

O projeto contará com um novo layout institucional, priorizando uma interface visual limpa, moderna e profissional.

### Requisitos

* Design responsivo.
* Experiência mobile first.
* Compatibilidade com celular, tablet e desktop.
* Navegação intuitiva.
* Organização clara dos serviços.
* Destaque para canais de atendimento.
* Componentes reutilizáveis.
* Estrutura preparada para futuras páginas.

## A reunião destacou que o site atual é antigo e possui problemas de responsividade, sendo necessária uma reformulação visual com foco especialmente em dispositivos móveis.

# 📝 2. Conteúdo institucional

O conteúdo do site será revisado para refletir o escopo atual de atuação da RTA Ambiental.

### Atividades

* Revisão dos textos institucionais.
* Atualização da lista de serviços.
* Organização das informações.
* Revisão dos títulos e descrições.
* Atualização de contatos.
* Organização de imagens e demais materiais.

A revisão é necessária porque parte dos serviços apresentados no site antigo não corresponde mais ao escopo atual da empresa.

---

# 📄 3. Páginas institucionais

A estrutura final das páginas será definida durante o planejamento, mas poderá contemplar:

* Página inicial.
* Institucional / Sobre a empresa.
* Serviços.
* Página individual dos serviços.
* Contato.
* Trabalhe conosco.
* Banco de Talentos.
* Política de Privacidade.
* Termos e documentos necessários.

---

# 📬 4. Formulário de contato

O novo site terá um sistema de contato integrado à plataforma.

### Funcionalidades

* Formulário de contato.
* Validação dos campos.
* Tratamento de erros.
* Proteção contra entradas maliciosas.
* Armazenamento ou encaminhamento das mensagens.
* Centralização das mensagens no painel administrativo.

A proposta prevê a centralização das mensagens recebidas pelo formulário por meio do painel administrativo.

---

# 👥 5. Banco de Talentos

Será implementado um **Banco de Talentos** para automatizar o recebimento de currículos e candidaturas.

### Funcionalidades previstas

* Formulário de candidatura.
* Cadastro de candidatos.
* Upload de currículo.
* Armazenamento das informações.
* Organização das candidaturas.
* Consulta pelo painel administrativo.
* Resposta automática ao candidato.
* Estrutura preparada para futuras expansões.

O Banco de Talentos foi identificado durante a reunião como uma funcionalidade relevante para reduzir o trabalho manual no recebimento de currículos.

---

# 🔐 6. Painel administrativo

O projeto incluirá um painel administrativo para gerenciamento do conteúdo e das informações recebidas pelo site.

### Funcionalidades

* Login administrativo.
* Gestão de conteúdo.
* Edição de textos.
* Gerenciamento de imagens.
* Gerenciamento de páginas e serviços.
* Centralização das mensagens recebidas.
* Gestão do Banco de Talentos.
* Controle de usuários.
* Controle de permissões.

A proposta prevê um painel administrativo capaz de permitir a edição de textos, imagens e páginas de serviço sem necessidade de alteração direta no código.

---

# 👤 7. Múltiplos usuários e permissões

O painel administrativo contará com diferentes níveis de acesso.

### Perfis previstos

* **Administrador**
* **Comercial**
* **Marketing**
* **Atendimento**

Cada usuário deverá possuir seu próprio acesso e permissões compatíveis com sua função.

A proposta do Pacote 5 prevê múltiplos logins com permissões por função.

---

# 🤖 8. Atendimento via WhatsApp / Chatbot

O projeto prevê a integração do atendimento do site com um **chatbot do WhatsApp**.

### Objetivos

* Facilitar o contato com visitantes.
* Automatizar respostas iniciais.
* Direcionar o usuário para o canal adequado.
* Reduzir o tempo de resposta.
* Complementar os canais atuais de atendimento.

A modernização do atendimento via WhatsApp ou chatbot foi discutida durante a reunião como uma alternativa ou complemento ao atendimento tradicional.

---

# 🔎 9. SEO

A plataforma será estruturada considerando boas práticas de SEO técnico.

### Implementações previstas

* Estrutura semântica.
* Metadados.
* URLs amigáveis.
* `robots.txt`.
* `sitemap.xml`.
* Títulos e descrições.
* Organização das páginas.
* Otimização de performance.
* Estrutura preparada para mecanismos de busca.

A proposta inclui especificamente `robots.txt` e `sitemap.xml` como parte do SEO técnico.

---

# 📊 10. Google Ads

Após a padronização técnica do site, a estrutura estará preparada para suportar estratégias de Google Ads.

### Etapas

1. Padronização técnica do site.
2. Estruturação das páginas.
3. Configuração necessária para campanhas.
4. Consultoria inicial.
5. Implementação das campanhas conforme estratégia aprovada.

Durante a reunião foi definido que a estrutura técnica do site deverá ser organizada antes da implementação das campanhas.

---

# 🛡️ 11. Segurança

A aplicação deverá seguir boas práticas de segurança para proteger os dados enviados pelos usuários e os recursos administrativos.

### Pontos de atenção

* Validação de dados.
* Sanitização de entradas.
* Proteção dos formulários.
* Autenticação.
* Controle de autorização.
* Proteção da área administrativa.
* Controle de acesso por função.
* Proteção de dados sensíveis.

A proposta prevê proteção do formulário contra ataques comuns e validação como parte do escopo de segurança.

---

# 📱 12. Responsividade

Todo o projeto será desenvolvido considerando diferentes tamanhos de tela.

### Ambientes

* 📱 Smartphone
* 📱 Tablet
* 💻 Notebook
* 🖥️ Desktop

A responsividade é um requisito central do novo projeto devido às limitações identificadas no site atual.

---

# 🚫 13. Funcionalidades fora do escopo

A seção de **Novidades** não será implementada nesta fase.

A decisão foi tomada porque a manutenção constante de conteúdo nessa seção não é considerada prioridade neste momento.

Novas funcionalidades poderão ser adicionadas futuramente mediante planejamento e aprovação.
